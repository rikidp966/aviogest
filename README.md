# AvioGest

Gioco gestionale di una compagnia aerea, nel browser e sul telefono.

Scegli la flotta e la configurazione delle cabine (Business, Premium Economy, Economy), apri rotte, fissa i prezzi per classe, costruisci basi e hub, organizza rotazioni ed equipaggi, fai marketing e tieni testa ai concorrenti.

Si gioca in tutto il mondo: 109 aeroporti in 6 continenti, ognuno con il suo fuso orario, aerei di lungo raggio (A321XLR, A330neo, 787, A350, 777, A380), voli che passano la mezzanotte e turni degli equipaggi con piloti di rinforzo e soste in albergo.

**Gioca online:** https://rikidp966.github.io/aviogest/

Online le partite si salvano nel browser del dispositivo che usi.

## In locale

Serve Node.js. Dalla cartella del progetto:

```
node server.js
```

Poi apri http://localhost:5190. Con il server acceso le partite e la classifica si salvano in `data/`, e il gioco si apre anche dai telefoni sulla stessa rete Wi‑Fi (l'indirizzo compare all'avvio).
